# 向上生长 · 毕业出路地图

计算机专业职业规划课的交互网站。以“我”为树根，向上展开六大方向、31 条具体路径。叶节点包含方向介绍、所需能力与本人指定的个人匹配度。

## 本地预览

需要 Node.js 20 或以上版本，无第三方依赖，无需 `npm install`。

```bash
npm run dev
```

打开终端显示的 `http://127.0.0.1:4173`。修改后刷新浏览器。

```bash
npm run build
npm run preview
```

## 已实现

- 六条向上生长的彩色树枝、中文节点与短说明。
- 鼠标拖动、滚轮缩放、触控平移与双指缩放。
- 缩放按钮、查看全图、图例定位分支。
- 点击节点打开详情卡片，Esc 关闭；节点可通过 Tab 和回车操作。
- 导出完整地图为 4520 × 3000 PNG；浏览器无法生成 PNG 时回退到 SVG。
- 手机布局、减少动态效果设置支持。

导出范围固定为整棵树，独立于当前平移、缩放与详情面板状态。字体使用系统中文字体，不请求外部字体服务。

## 修改内容

`src/data.js` 集中保存文字、颜色和坐标；`src/profiles.js` 保存 31 个叶节点的能力说明、匹配等级与条长；`src/map.js` 绘制 SVG 树；`src/main.js` 负责交互和导出；`src/styles.css` 负责页面样式。原生 JavaScript + SVG 保持网站轻量，并可直接静态托管。

地图上的“直博”节点合并展示博士相关路径，卡片补充说明本科直博及读研后攻博。方案架构师等长期发展方向不表示本科毕业即可直接进入。

## 发布到 GitHub Pages

目标仓库：`VincentLogan/career-map`。

1. 将项目提交并推送至仓库的 `main` 分支。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 在 **Actions** 打开 `Deploy career map to Pages`，点击 **Run workflow**，选择 `main` 运行。网站采用手动发布，推送代码不会直接更新线上页面。
4. 发布成功后查看 Actions 返回的实际网址，通常为 `https://vincentlogan.github.io/career-map/`。

所有资源使用相对地址，适配仓库子路径。此项目不需要数据库、API key 或运行时服务器。
